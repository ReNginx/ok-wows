# UU 截图与 OCR 标注

`coco_annotations.json` 沿用游戏资源的 COCO 结构：

- `images`：首页 `images/home.png`（1000 × 688）及加速成功页 `images/accelerated.png`（1750 × 1204）。
- `categories`：区域名称，例如 `UU-Home-Card-3`。
- `annotations[].bbox`：参考截图中的 `[左, 上, 宽, 高]`。
- `uu_ocr`：关联区域和 OCR 文字规则，由 UU 专用识别器读取。

首页四张卡片、名称栏及“我的游戏”入口根据实际截图标注。当前战舰世界在第三张卡片，
但程序会识别四张卡片的名称，因此调整首页顺序后仍可定位。
加速成功页截图采集于 2026-09-09，`UU-Detail-Title` 已按左侧游戏名称校准。
详情页区域通过 `detail_reference_image_id` 关联此截图，bbox 使用对应原图像素坐标。
`UU-Detail-Content` 保留宽范围 OCR，以读取成功状态及可见错误提示。
识别需同时确认游戏名称及“停止加速”等成功文字；延迟数值、节点、计时和曲线不参与判断。
“启动游戏”本身不能证明加速成功。截图是区域标注和回归验证样本，不作整张图片匹配。

运行流程：先 OCR `home_titles` 名称栏，找到设置中的“UU 游戏名称”，
再只 OCR 对应卡片的 `content` 区域检查状态。名称匹配且未显示已加速状态时，
点击该卡片 `click_region` 指定的图标框中心，即游戏名称上方的图片中心。
无需先出现加速按钮文字；OCR 文字的位置只用于识别和校验所属游戏。
点击一次后等待新画面的加速状态，避免重复点击。
`texts.ready` 用于确认成功，`texts.blocked` 用于报错。
首页找不到目标时，尝试详情页搜索区域和已标注的“我的游戏”入口。
没有经过标注的详情页图标不执行点击，等待或报错，不回退到点击文字框。

矩形按当前 UU 窗口尺寸缩放；1750 × 1204 的 175% DPI 窗口与参考图对应。
截图只包含 UU 窗口本身，不应包含窗口外阴影或其他应用。
比例变化超过 `aspect_ratio_tolerance` 时停止识别，避免错误使用原布局。
OCR 裁剪结果会加回裁剪偏移用于区域归属判断。
点击坐标使用缩放后的图标框中心，再加上 UU 窗口的屏幕位置。

修改区域时更新对应 `bbox` 和 `area`；修改按钮名称时更新 `uu_ocr.texts`，
无需更改 Python。更换参考截图时同步更新 `images` 的尺寸及区域坐标。
使用 COCO 标注工具编辑时，请保留扩展字段 `uu_ocr`，然后重启应用以加载更改。
这些资源独立于战舰世界的 `21x9`、`16x10` 和 `16x9` 资源，不切换游戏截图目标。

JSON 负责定位和文字匹配。若 UU 以管理员权限运行，本应用仍需相应权限才能输入。
