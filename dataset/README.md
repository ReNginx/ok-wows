# 战斗截图数据集

在 **Auto PVE Battle** 配置中开启 **采集战斗截图（Capture Battle Dataset）** 后，从首次识别到战斗界面或大地图起计时，满 60 秒采集第一组，此后每分钟采集一组。开关默认关闭，关闭时不执行采集计时、采集用的地图切换或图片保存。

每组包含原始分辨率的无损 PNG：正常战斗界面一张、大地图界面一张。程序按 `M` 打开地图，确认后截图，再按 `M` 返回；采集不会重新设置航点。两张图是先后采集，并非同一时刻。

目录按每场战斗的入场时间区分，同组文件使用相同时间戳；随机后缀用于防止时钟重复时覆盖旧图：

```text
dataset/
  20260910_120000_123456_a1b2c3d4/
    20260910_120100_234567_e5f6a7b8_battle.png
    20260910_120100_234567_e5f6a7b8_map.png
    20260910_120200_345678_c9d0e1f2_battle.png
    20260910_120200_345678_c9d0e1f2_map.png
```

排队、加载、结算、击沉页面不采集。无法确认进入大地图时跳过该组并记录日志；恢复后不补拍积压的分钟。每场战斗重新计时，已有文件保留，截图子目录不提交到 Git。
